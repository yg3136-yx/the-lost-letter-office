# The Lost Letter Office

An interactive storybook experience set in a mysterious post office after midnight. Three undelivered letters—**To Yesterday**, **Never Sent**, and **To Tomorrow**—represent nostalgia, regret, and hope.

## Main interactions

- Change the weather between rain and clear skies.
- Adjust the brightness of the desk lamp.
- Observe how each letter responds to combinations of weather, light, patience, and previous discoveries.
- Reopen discovered letters to read their messages again.
- Use **Reset evening** to return the room and all discoveries to their initial state.

The interface intentionally keeps its exact unlocking rules hidden. Subtle changes in handwriting, ink, glow, and movement encourage exploration without turning the experience into a list of instructions.

## Run locally

No build process or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

For the most consistent local behavior, you can also serve the directory with any simple static web server.

## Technology

The project uses semantic HTML, CSS animations and responsive styling, and vanilla JavaScript for state management, event listeners, conditional interaction logic, timers, and visible feedback.
